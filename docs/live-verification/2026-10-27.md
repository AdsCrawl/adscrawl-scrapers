这些结果来自真实 AdsCrawl SDK 请求，不是历史 `results/` 样例或模拟测试。每站运行现有 `test.py`，遇到首个失败暂停该站剩余用例；每站限时 300 秒。首轮逐站运行；修复后复测分两组执行，每组最多一个浏览器会话。部分通过仅覆盖表中列出的功能，不代表整个站点可用。空结果不能证明抓取成功。

后续请求默认使用 US 美国线路；站点显式指定的地区优先。JSON 中的 countries 记录采集启用后实际创建的浏览器国家，早期未记录的请求保持空值。

已定位的代码问题已修复并提交，JSON 保留首轮及复测记录；每站表格使用最新一次实测结果。未完成的测试和仍受阻的功能不标为通过。外部站点、数据、代理线路和访问限制会变化，本报告只证明该日期、该用例的观察结果。API Key、CDP URL、Cookie 和原始调试日志不公开。

## 修复与额外验证

- **传输层**：修复 GET 导航的 Accept 请求头被浏览器覆盖、无关二进制 XHR 解码失败、后台任务和会话关闭挂起、异步生成器及取消时的清理。远程回显验证 JSON POST 返回 HTTP 200 且请求体匹配；Accept 复测返回 HTTP 200 且值为 application/json。
- **通过复测的站点修复**：Rightmove JSON 请求及分页、Fashionphile 分页链接、App Store 评论请求、IMDb 页面就绪等待、Reddit 请求选项。
- **已修复但未整套通过**：Target 新版价格模块兼容真实响应的 3 个规格，但最新请求遇到代理连接失败；Zoopla 懒加载修复后首个详情获得 nearby 字段，后续详情 HTTP 403；Google Jobs 循环已有上限，但目标仍返回异常流量验证页；Expedia 参数类型、Crunchbase 异常处理、Amazon/Threads 并发清理等已修复，在线访问仍受阻。
- **本地离线验证**：Python 3.10 和 3.12 各 42 项测试通过；全部 81 个模块的导入、入口和请求配置检查通过。
- **CI**：[代码提交 bde49ce 的 GitHub Actions](https://github.com/AdsCrawl/adscrawl-scrapers/actions/runs/40468295849) 已通过 Python 3.10、3.12、3.13 的离线测试、目录检查及构建。离线 CI 通过不代表所有目标网站在线可抓取。
- **会话清理**：本轮记录的 262 个远程会话，收尾查询时仍活跃的任务所属会话为 0。
